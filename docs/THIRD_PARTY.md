# Third-party references

This release contains original analysis artifacts; it does not bundle model
weights or upstream benchmark source datasets. Use upstream releases and their
licenses when conducting new evaluations.

- RULER: https://github.com/NVIDIA/RULER
- LongMemEval: https://github.com/xiaowu0162/LongMemEval
- LoCoMo: https://github.com/snap-research/locomo
- Sentence encoder: https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2

Exact archived benchmark and encoder revision identifiers are retained in
`data/audit/public_report.json` and `docs/PROVENANCE.md`. Dependencies named in
requirements.txt retain their own licenses. Cited paper text is not relicensed.
